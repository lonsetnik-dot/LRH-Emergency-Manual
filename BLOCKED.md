# Blocked — decisions waiting on Lon

One entry per decision, in the format `EXECUTION-BRIEF.md` §1 specifies. Numbered
`B-01` onward, never renumbered. Each says what is parked on it, so the ones that
unblock the most work can be answered first.

**Nothing here was guessed at, and nothing here stopped the run.** When a decision
appeared, the work that did not depend on it carried on.

Two kinds of entry:

- plain — a question. Everything not downstream of it continued.
- `HARD STOP` — work on that *file* stopped: a medical conflict, a frozen
  identifier that would have to change, or a clinical value that would have to be
  written into a shipped path.
