FEEDBACK
This is the ladder for a patient you cannot intubate. If there is no pulse, this is not the screen — go to cardiac arrest. If there is a pulse but no breathing and you can ventilate them, that is rescue breathing, not this ladder. DAS 2025 is written for anesthesia and gives no arrest algorithm; its wake-the-patient options do not exist here.
