    THE STANDARDS — ITEM BY ITEM, SIZE BY SIZE
    One row per size, because “supraglottic airways 1–5: present” hides the only question worth asking — whether the size for the patient in front of you is in that drawer. Set each row to a location or to GAP.
    KITS — AUDITED AS KITS
    A kit has one location and a contents list; a kit that is present but missing two items is not ready. Contents are the same strings the cart labels and the procedure cards use — if they ever disagree, the build breaks.
    KIT CHECK — PILOT (CHEST TUBE)
    Walk to the kit, work down the list, then EXPORT CSV. The check lives on this device only — the CSV is the only way it leaves the iPad, so an un-exported walk is not a record.
