How this stays current
  • Monthly crawl. PubMed search plus a fingerprint of each body’s index page. A move opens an issue naming the affected cards.
  • Review interval. 180 days for high-impact sources, 365 for the rest. Passing it lists the source whether or not anything was detected.
  • A quiet month means no change detected — never nothing changed. The crawler shortens the notice; the calendar guarantees the look.
